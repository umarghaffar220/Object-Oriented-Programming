# C++ Object-Oriented Programming (OOP) Practice

Welcome to my C++ OOP Practice Repository!

This repository contains practice questions and coding exercises based on the **Deitel & Deitel C++ How to Program** book, along with additional basic questions to build a strong understanding of Object-Oriented Programming.

## 📚 Topics Covered

- Classes and Objects
- Data Members and Member Functions
- Access Specifiers (Public, Private, Protected)
- Constructors and Destructors
- Encapsulation
- Friend Functions
- Inheritance
- Polymorphism
- Function Overloading
- Operator Overloading

## 🎯 Purpose

- Understand the basic concepts of OOP.
- Practice C++ programming through different questions.
- Improve logical thinking and problem-solving skills.
- Build a strong foundation in Object-Oriented Programming.
